## How to use this document

This continues the existing checklist. Parts 1–3 asked about the company and
confirmed what we had already been told; Parts 4–13 ask about **how the agency
actually works**, because the system now has working rules built into it that
only CDE can confirm.

Every question states what our system currently assumes, so there is something
concrete to correct rather than a blank page to fill.

Each item is tagged:

- **[BLOCKING]** — we cannot finish the system or the paper without an answer.
- **[IMPORTANT]** — an answer materially improves the system.
- **[OPTIONAL]** — useful, drop it if time is short.

There are 57 questions in total, of which 18 are blocking. If the meeting is
short, ask the blocking ones first; the rest can follow by email.

*Note to ourselves: the answer type in `[brackets]` is the Google Form field to
use. Remove these brackets before sending.*

## Follow-ups to Parts 1–3

Two items in the existing checklist need a small addition. They can be asked
verbally rather than added to the form.

**On the AWOL rule.** Part 3 confirms termination at five AWOL incidents but not
the period over which they are counted. This is asked as question 9.2 above,
because the system cannot apply the rule without it.

**On the folders.** Part 3 asks whether the male/female folders are the same
filing system as Folder 1/2/3. Whichever the answer, we also need to know
whether the male/female split carries any **meaning** for how an applicant is
handled, or whether it is only a convenience for finding paper folders quickly.
Our system reproduces the Folder 1/2/3 logic but does not separate records by
sex, and we should confirm that is acceptable.
